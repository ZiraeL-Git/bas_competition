# bas_competition

Минимальная рабочая база для поэтапной отладки связки OpenMV -> Geoscan Pioneer.

Сейчас в корне оставлены только файлы, которые нужны для первого стабильного этапа:

| Файл | Где запускать | Что делает |
| --- | --- | --- |
| `READY_OPENMV_MARKER.py` | OpenMV IDE / камера OpenMV | Ищет прямоугольную метку через `find_rects()` и отправляет два байта `cx, cy`. |
| `READY_GEOSCAN_PIONEER.lua` | Pioneer Station / дрон | Читает два байта с OpenMV по UART и показывает результат LED-ами. |

Полет, взлет, посадка и сложное распознавание временно убраны. Сначала нужно надежно подтвердить, что скрипты вообще запускаются, OpenMV видит метку, а Pioneer получает координаты.

## Подключение

- OpenMV: `UART(3, 9600)`
- Pioneer: `Uart.new(4, 9600, Uart.PARITY_NONE, 1)`
- Обязательно соединить общий `GND`.

OpenMV отправляет координаты как в Ванином рабочем примере:

```text
byte 1 = cx
byte 2 = cy
```

Теперь OpenMV отправляет пару байтов постоянно. Если метка не найдена, отправляется центр кадра `80, 60`. Это сделано специально для проверки UART: Pioneer должен перестать гореть красным даже без метки, если связь работает.

Кадр OpenMV: `160x120`, поэтому центр примерно `x=80`, `y=60`.

## Как запускать

### 1. OpenMV

1. Открыть `READY_OPENMV_MARKER.py` в OpenMV IDE.
2. Подключить камеру.
3. Запустить файл или сохранить его на камеру как `main.py`.
4. Поднести метку.

Признаки работы:

- красный LED OpenMV: метка не найдена;
- зеленый LED OpenMV: метка найдена;
- в консоли OpenMV печатается `X=... Y=...`.

### 2. Pioneer

1. Открыть `READY_GEOSCAN_PIONEER.lua` в Pioneer Station.
2. Загрузить и запустить скрипт на дроне.

Признаки работы:

- красный LED Pioneer сразу после запуска: скрипт стартовал, но координат нет;
- синий LED: координаты пришли, метка левее центра;
- зеленый LED: координаты пришли, метка правее центра;
- желтый LED: координаты пришли, метка примерно по центру по X.

Если Pioneer остается красным, значит он не получает байты по UART. Тогда проверять нужно не распознавание, а порт `UART4`, провода `TX/RX`, общий `GND` и скорость `9600`.

## Что делать дальше

Разрабатывать дальше лучше по одному шагу:

1. Добиться стабильного LED-отклика на Pioneer при движении метки перед OpenMV.
2. Добавить отдельный тестовый файл только для взлета.
3. Добавить удержание высоты.
4. Добавить движение по `cx, cy`.
5. Добавить посадку.
6. Только после этого возвращать ArUco/AprilTag или более сложное распознавание.

Все старые прототипы, эксперименты и вспомогательные файлы убраны в `Архив/`.
