# START_HERE

Короткая памятка перед зачетной попыткой.

По обновленному заданию TurtleBro движется сам. Из этого репозитория запускаются только компьютерное зрение и управление дроном.

## Порядок запуска

### Шаг 1. OpenMV камера

```text
OpenMV IDE -> открыть openMV_script.py -> Run
```

Проверить:

- камера направлена вниз;
- ArUco-метка попадает в кадр;
- при обнаружении маркера включается зеленый LED OpenMV;
- UART подключен к Pioneer;
- скорость UART: `115200`.

### Шаг 2. Pioneer Station

```text
Pioneer Station -> открыть pioneer_mission.lua -> загрузить на дрон -> Run
```

Проверить LED-индикацию:

| Этап | Индикация |
| --- | --- |
| Взлет | красный |
| Поиск маркера | зеленый мигающий |
| Маркер найден и посадка | синий постоянный |
| После посадки | программный `DISARM` |

### Шаг 3. TurtleBro

Ничего не запускать. Платформа движется сама по условию задания.

Перед стартом только проверьте, что маркер закреплен на платформе и хорошо виден сверху.

### Шаг 4. Лог

Основной лог сохраняет `pioneer_mission.lua` в `mission_log.txt`.

Если нужен дополнительный лог на ноутбуке:

```bash
python mission_logger.py
```

## Перед стартом

1. Показать судьям `ARM` и `DISARM`, если это требуется регламентом.
2. Убедиться, что OpenMV видит ArUco-метку и отправляет `FOUND,cx,cy,size`.
3. Убедиться, что Pioneer получает данные с OpenMV.
4. Проверить, что знак коррекции ведет дрон к маркеру.
5. Проверить аварийную посадку.
6. Только после этого начинать зачетную попытку.

## Если что-то пошло не так

Маркер не обнаруживается:

- проверьте освещение;
- проверьте фокус и направление OpenMV;
- проверьте, что используется ArUco-метка из задания;
- уменьшите `RECT_THRESHOLD`, если квадратов-кандидатов нет;
- увеличьте верхнюю границу `BLACK_THRESHOLD`, если черные области выглядят серыми;
- уменьшите `MIN_DARK_BORDER_CELLS`, если рамка видна, но метка не принимается;
- проверьте фильтры размера `MIN_SIDE_PX` и `MAX_SIDE_PX`.

Дрон уходит от маркера:

- поменяйте знак коррекции в `pioneer_mission.lua`;
- проверьте ориентацию камеры;
- уменьшите `PIXEL_TO_METER` для безопасного теста.

Дрон осциллирует:

- уменьшите `PIXEL_TO_METER`;
- увеличьте `DEAD_ZONE_PX`;
- проверьте, что платформа не движется слишком быстро для текущих настроек.
